HOW CAN WE PREVENT IT?

SELF CHECK
행동 전 대상과 목적을 다시 확인
PLACE KEEPING
중단 후 작업 위치를 명확히 확인
3-WAY COMMUNICATION
지시·복창·확인으로 전달 오류 예방
STOP WHEN UNSURE
불확실하면 멈추고 확인
PEER CHECK
중요 작업은 동료와 독립적으로 확인
PROCEDURE USE
기억보다 절차와 체크포인트 활용
