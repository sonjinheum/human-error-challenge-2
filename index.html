인간은 누구나 실수할 수 있습니다.

중요한 것은 더 집중하라고 요구하는 것만이 아니라, 실수가 발생하기 어려운 작업환경과 확인 장치를 만드는 것입니다.

HOW CAN WE PREVENT IT?

SELF CHECK
행동 전 대상과 목적을 다시 확인
PLACE KEEPING
중단 후 작업 위치를 명확히 확인
3-WAY COMMUNICATION
지시·복창·확인으로 전달 오류 예방
STOP WHEN UNSURE
불확실하면 멈추고 확인
PEER CHECK
중요 작업은 동료와 독립적으로 확인
PROCEDURE USE
기억보다 절차와 체크포인트 활용
